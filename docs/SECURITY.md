# Сообщения о проблемах безопасности

Для конфиденциальной уязвимости используйте GitHub Private Vulnerability Reporting в разделе Security этого репозитория, если функция включена. Если она недоступна, создайте issue только с просьбой предоставить приватный канал, без деталей эксплуатации и секретов.

Обычные ошибки геометрии и совместимости можно отправлять в Issues. Удалите личные пути, данные моделей, токены и пароли из приложенных журналов.

Этот сервер работает локально и может записывать CAD-файлы и изменять собственные открытые документы. Запускайте его через доверенный MCP-клиент с отдельной рабочей папкой. HTTP-сервер и удалённый сетевой доступ в этой поставке не предусмотрены.

Стабильная политика поддерживаемых версий пока не установлена; текущая ветка — предварительная разработка. Подтверждённые исправления публикуются с указанием затронутой версии.
