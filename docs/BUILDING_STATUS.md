# Строительные инструменты — 0.4.0.dev1

Это промежуточная реализация, а не завершение согласованного плана.

## Что работает

| Возможность | Подтверждение | Ограничение |
|---|---|---|
| Типизированный строительный проект, этажи, стены, проёмы, помещения, мебель | Модульные тесты и вызовы MCP | Пока нет осей и перекрытий |
| ID, ревизии, контроль предыдущей версии, атомарная запись | Тесты устаревшей ревизии и блокировки записи | Обнаружение ручных изменений CDW ещё не реализовано |
| Проёмы привязаны к стенам | Проверка длины, высоты, пересечения проёмов | Привязка по расстоянию от начала стены |
| Площадь помещения по внутренним граням | Проверено до и после изменения стены | Только простой выпуклый замкнутый контур; без колонн и отделки |
| Мебель и зоны использования | Каталог восьми типов; тесты столкновений | Геометрия предметов пока габаритная; размеры примеров не являются нормами |
| Пересечения мебели и стен; блокирование двери мебелью | Геометрические тесты | Одностворчатая дверь, сектор 90°; столкновения створки со стенами не проверяются |
| Локальный нормативный поиск FTS5 и resources | MCP и модульные тесты | Только каталог документов: **проверенных нормативных правил пока 0** |
| Четыре состояния нормативного вычислителя | Синтетические тесты дат, границ и исключений | Не подключён к реальному набору правил проекта |
| Нативная M3D и CDW из AEC.cdt одним вызовом | `tests/integration/building_acceptance.py`, КОМПАС v25 | Экспериментальный предварительный план; узлы стен пока перекрывающиеся тела |
| Сохранение и повторное открытие | Проверены 7 тел, габариты, объём и поля листа | Простой однокомнатный технический пример, не пятизонный офис приёмки |
| Ограничение размера растрового предпросмотра модели | Проверено через CalcRasterScale и визуальный просмотр PNG | 1600×1200 как целевые габариты; размеры CAD не меняются |

Для растра чертежа явно сбрасывается Scale=1: КОМПАС наследовал уменьшенный масштаб после экспорта модели. Проверено последовательным экспортом M3D и CDW: изображение листа вновь имеет 2487×1761 пиксель при 150 dpi. Предварительный план визуально проверен; это контуры без необходимого для выпуска полного оформления.

Последний прогон Python: 19 тестов пройдено, один интеграционный тест пропущен. Отдельный нативный прогон строительного примера выполнен. Итоговые M3D/CDW оставлены открытыми; временные копии закрыты. Регрессия машиностроения здесь ограничена Python-тестами, полный повтор нативных инженерных сценариев не выполнялся.

## Использование

1. `building_furniture_catalog` — размеры редактируемых примеров, отдельно от нормативных требований.
2. `building_project_save(project, expected_revision)` — создание (`null`) или сохранение следующей ревизии. Все размеры задаются явно. Неизвестные значения фиксировать в assumptions, не снимать с масштаба картинки как точные.
3. `building_project_check(project_id)` — геометрические проверки без изменения CAD.
4. `norm_search(request)` — поиск с датой и контекстом. Для расстояния между перегородками нужны тип измерения, ограничивающие поверхности, назначение, численность и условия доступности. Метаданные не использовать как численную норму.
5. `building_preview(project_id)` — новый экспериментальный M3D и план CDW в уникальной папке ревизии. Существующие файлы не обновляются; пользовательские слои не затрагиваются.

Полный проект: `kompas://building/{project_id}`. Карточка источника: `kompas://norm/{rule_id}`. Входной JSON — основной источник параметров. Идентификаторы геометрии пока сохраняются в именах операций и внешнем отчёте, не как полноценные атрибуты управляемых элементов CDW.

## Нормативные источники и остающаяся работа

Каталог `src/kompas_mcp/data/office_norms.json` содержит официальные ссылки и дату проверки метаданных 15.09.2026. Полные тексты и изменения всего согласованного набора ещё не изучены. Поэтому нет заявлений о соответствии ГОСТ или подтверждённых чисел ширины проходов. Изменения с будущей датой не должны применяться к более раннему проекту. Размеры технического примера выбраны исключительно для испытания адаптера.

Для полной поставки остаются: проверенные карточки СП/ГОСТ и санитарных требований; применимость и строгая проверка; связанные разрезы/фасады; стены с правильными узлами и перекрытия; автоматическое обновление управляемой геометрии с обнаружением ручных правок; размеры, обозначения, ведомости, PDF с визуальной проверкой; пятизонный офисный пример и полная приёмка. Приложение АС/АР не используется.

## Воспроизведение

Из корня репозитория после setup.ps1:

```powershell
./.venv/Scripts/python.exe scripts/export_schemas.py
./.venv/Scripts/python.exe -m pytest tests -q
./.venv/Scripts/python.exe tests/integration/building_acceptance.py C:/CAD/building-acceptance-new
```

Для приёмки нужна новая папка: существующий проект без expected_revision намеренно не перезаписывается. Пользовательские настройки MCP не изменялись. Версия dev не является готовой заменой рабочего пакета.
