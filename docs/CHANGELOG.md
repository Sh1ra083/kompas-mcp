# 0.4.0.dev1 — подготовка исходной публикации

- Экспериментальные строительные проекты, каталог мебели, геометрические проверки и локальный нормативный поиск.
- Предварительные M3D/CDW из AEC-шаблона; путь шаблона переопределяется через KOMPAS_MCP_AEC_TEMPLATE.
- Предпросмотр крупных моделей рассчитывает ограниченный размер растра; для чертежа масштаб растра явно сбрасывается.
- Исходная публикация с MIT, Windows CI, нейтральными примерами подключения.
- Документация находится в docs, общие интеграционные проверки — в tests/integration. Учебные сценарии и материалы отдельных практических работ исключены.
- Полный исходный план не принят. Нормативных карточек verified пока нет; dev-версия не является стабильным выпуском.

# 0.1.1 — исторические изменения

Испытание на пользовательском чертеже обнаружило неверное направление выреза в 0.1.0. КОМПАС мог вернуть успешное состояние операции без удаления материала. Старый тест корпуса не проверял объём удалённых отверстий и поэтому пропустил ошибку. Геометрия вырезов из старой поставки подлежит повторной проверке; исправленный пакет не использует прежний отчёт как доказательство правильности отверстий.

- Для выдавливания добавления и выреза `reverse=false` теперь одинаково означает направление по нормали эскиза; `reverse=true` — обратное. Изменение глубины редактирует фактически используемую сторону операции.
- Вырез проверяет удалённый объём, возвращает его в `verification`; отсутствие удаления даёт `no_geometry_change`. Состояние могло измениться, автоматического отката нет; ошибка содержит ссылку и `restored=false`.
- Новый `model_check` позволяет включить геометрические условия приёмки в декларативный сценарий: тела, габариты, объём, числа выбранных геометрических объектов. Несоответствие даёт `verification_failed`.
- Просмотр дерева не падает на служебном объекте без `IFeature7`; такой объект имеет `diagnostic_available=false`, а не фиктивное отсутствие ошибок.
- Preview понимает устойчивые имена `isometric`, `front`, `back`, `top`, `bottom`, `left`, `right`. Новые модели используют Z-аксонометрию; автоматически созданные опорные плоскости скрыты.
- Добавлены проверки изменения глубины, направлений выреза и удалённого объёма отверстий.

Проверенная среда прежняя: КОМПАС-3D v25 Учебная x64. Более широкие ограничения остаются в COMPATIBILITY.md.
