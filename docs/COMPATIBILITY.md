# Совместимость и ограничения

Исторические нативные проверки выполнены на Windows 11 x64, КОМПАС-3D v25 Educational 25.0.0.2735 и Python 3.12 x64. Другие версии и редакции требуют отдельных испытаний. Обычный CI проверяет исходники и протокол без установленного CAD.

Наличие адаптера не гарантирует построение любой геометрии. Приведённый статус описывает проверенные режимы; после изменения операций нужны новые нативные проверки.

| Группа | Проверенные режимы | Ограничения |
|---|---|---|
| Документы | Создание, сохранение, рабочие копии, зависимости, контрольные копии | Сложные PDM-ссылки и исполнения отдельно не приняты |
| Эскизы | Отрезки, окружности, прямоугольники, горизонтальность, размер длины | Полная приёмка дуг, сплайнов, проекций и всех ограничений не завершена |
| Детали | Выдавливание и вырез с проверкой объёма, вращение, траектория, оболочка, ребро, фаска, скругление, булевы операции | Уклон и сложные зависимости требуют расширенной приёмки |
| Массивы и опорная геометрия | Линейный/круговой массив, зеркало, спираль, смещённая плоскость, ось, ЛСК | Возможности ограничены реализованными типизированными параметрами |
| Поверхности | Поверхность по сечениям, утолщение, сшивка, обрезка, смещение | Сложные направляющие и контроль гладкости не приняты |
| Листовой металл | Листовое тело, сгиб, распрямление выбранных сгибов | Универсальная развёртка не реализована |
| Сборки | Вставка, размещение, фиксация, замена, сопряжения совпадения и расстояния | Прочие сопряжения требуют приёмки; массив компонентов создаёт явные экземпляры |
| Пересечения | Геометрические пересечения компонентов верхнего уровня | Нет полного обхода вложенных подсборок |
| Чертежи | Ассоциативные виды и разрез, размеры, штамп, позиционные выноски, компоновка | Автоматической проверки всех наложений надписей и связей размеров нет |
| Проекционные связи | Компоновка сохраняет связи с базовым видом; противоречащий перенос отклоняется | Связанные виды не раскладываются независимо |
| Спецификации | Нативный SPW, группировка, явное обновление количества | Управляемая спецификация должна быть создана в текущем сеансе |
| Экспорт | STEP, STL, PDF, DXF и PNG; повторный импорт STEP | Конвертер должен быть доступен в установленной редакции |
| Ошибки | Неверные параметры, конфликт ограничений, неоднозначность, устаревшая ссылка, отказ построения, остановка пакета | Принудительное зависание CAD-ядра не испытывалось; тайм-аут не означает отмену операции |

Ссылки на топологию действуют только в текущем сеансе и ревизии. После изменения модели геометрию выбирают заново. Условная резьба не создаёт физических витков в STEP. Проверка успешного COM-статуса должна дополняться измерениями и контролем дерева.

Общие нативные сценарии находятся в [tests/integration](../tests/integration/). Запускайте их вручную в новой рабочей папке с установленным КОМПАСом. Учебные работы, их исходные PDF и исторические локальные отчёты в репозитории не хранятся.

Экспериментальная строительная часть имеет отдельные ограничения: [BUILDING_STATUS.md](BUILDING_STATUS.md). Полный первоначальный план и соответствие всем нормативным требованиям не заявляются.
